# Customer Churn Prediction System

## 1. Project Overview

Customer Churn Prediction System is a Data Science and Machine Learning project designed for a fictional telecommunications company called **TeleConnect**.

The objective is to analyze customer data, identify patterns associated with customer churn, and build a machine learning model that predicts which customers are likely to leave the company.

## 2. Business Problem

Customer churn occurs when customers stop using a company's products or services.

For a telecommunications company, losing customers can result in:
- Reduced recurring revenue.
- Increased customer acquisition costs.
- Loss of long-term customer relationships.
- Reduced business growth.

TeleConnect wants to understand why customers leave and identify customers who may be at risk of leaving.

## 3. Project Objectives

1. Understand customer demographics and subscription behavior.
2. Identify factors associated with customer churn.
3. Perform exploratory data analysis.
4. Analyze customer behavior using SQL and statistics.
5. Develop machine learning models to predict churn.
6. Evaluate model performance using appropriate metrics.
7. Explain model predictions using SHAP.
8. Build an interactive dashboard to communicate insights.

## 4. Dataset

**Dataset:** IBM Telco Customer Churn

**Source:** https://www.kaggle.com/datasets/blastchar/telco-customer-churn

The dataset contains customer information, subscribed services, account details, billing information, and churn status.
